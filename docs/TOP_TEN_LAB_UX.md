# Ten interactive lab experiences — 1.17.0+20

Open **Lab options → Interactive challenge** in any lab below, or its named shortcut in **Inspect**. These are the ten enhancements proposed for the ten priority labs; they complement the existing apparatus, graphs, worksheets and studio workbenches.

1. **Second Law / F = ma (`s04-e01`) — Predict the acceleration.** Draw an acceleration vector or adjust its two components, reveal the source vector and inspect the vector discrepancy. Change signed force or mass and run the original cart. Axes rescale visibly; a changed setup invalidates the old comparison.
2. **Energy Conservation (`s05-e03`) — Energy replay.** Explicitly record a run, stop, then scrub up to 600 actual model frames. The bead position and kinetic, potential and dissipated-energy bars share one captured frame and time. Replay never rewinds the source model. No interpolated or invented trajectory points; setup changes stop recording. The recorded bowl curvature is retained for replay.
3. **Circuits (`s10-e04`) — Circuit path debugger.** Select two component terminals to highlight a conducting path in the actual circuit graph. Open switches and ideal voltmeters are excluded from conduction. Open/close a real source switch and undo that edit. The existing modified nodal analysis solver reports floating nodes, ideal-source conflicts, component currents and KCL residual. A connectivity path alone is explicitly not proof of a complete powered loop.
4. **Wave Properties (`s08-e00`) — Two wave probes.** Drag two independent probes, compare simultaneous displacements and their synchronized one-period traces, and mark the next crest to calculate its source-time arrival at each probe. Both directions use the same harmonic function as the apparatus. Upstream probe order and zero amplitude receive explicit guidance. Probe positions also have sliders and buttons. Traces are calculated from the current harmonic model, not recorded measurements.
5. **Lenses (`s09-e02`) — Build the principal rays.** Select the parallel or central outgoing ray and construct its angle by dragging or sliders. Reveal the model rays and angular discrepancies. Virtual backward extensions are dashed; the real/virtual/infinity result, signed image distance and magnification come from source readings. The diagram labels its vertical exaggeration and limited viewport; numerical distances are not clipped.
6. **Heat Transfer (`s13-e01`) — Temperature explorer.** Drag the source probe along the steady-conduction rod. Position, temperature, temperature–position graph, gradient and heat rate remain linked to the actual controls and readings. Reservoir temperature changes update the profile. Other transfer modes explain why the spatial conduction probe is unavailable. This is a steady profile, not a fabricated transient animation.
7. **Induction (`s11-e04`) — Move the magnetic source.** Drag the source axially past the receiver coil, change signed velocity, open/close the receiver and run the source model. Position, flux, linkage, EMF, current and polarity stay synchronized. This adapts the proposed boundary interaction to the app's existing finite-loop model: dragging while paused changes initial position; the explicit source velocity sets instantaneous flux change. Pointer speed is not presented as a measured physical speed.
8. **Buoyancy (`s14-e02`) — Predict the waterline.** Drag a predicted submerged fraction or use its slider/buttons, reveal calculated equilibrium and inspect discrepancy in percentage points. Change object/liquid density and explore floating, neutral and sinking cases. The feedback distinguishes bottom support from freely floating equilibrium; held-position readings are not substituted for equilibrium.
9. **Vernier Caliper (`s01-e01`) — Find the matching graduation.** Tap/drag the vernier scale or select a numbered graduation before revealing main-scale value + coincident division × least count − signed zero error. Jaw opening and zero error use the actual instrument controls. The diagram uses 0.9 mm vernier spacing and 0.1 mm least count.
10. **Photoelectric Effect (`s15-e01`) — Six-trial threshold hunt.** Independently vary wavelength/frequency and irradiance, capture six explicit trials and narrow an energy-threshold wavelength bracket. Each row retains irradiance, photon-energy permission, actual emission, maximum kinetic energy and collector current. Zero irradiance does not become false evidence of a sub-threshold wavelength. Mixing work functions requires starting a new hunt. A completed hunt can be restarted explicitly.

## State and accessibility

- The existing workspace owns all physical controls, models, clocks and calculations. The new panel does not create a second simulation engine.
- Predictions, replay frames, connectivity selection and hunt evidence survive closing/reopening the panel during the same lab visit. They are intentionally temporary and are not saved worksheets or recorded Trials.
- Source-control changes follow normal app session behavior. No automatic trial insertion, mastery completion, learner-note rewrite or preference writes are added. The switch undo retains a private configuration only in memory.
- Drag alternatives include labeled sliders/buttons, numbered choices and terminal buttons. Feedback is next to its prediction/capture action and announced as a live region. Long content scrolls; the close button remains outside the scroll view.
- Source setup changes label earlier predictions/replays as belonging to the previous setup.

## Validation

`test/focus_lab_test.dart` checks real source callbacks for all ten labs, energy conservation across captured replay frames, replay isolation from source time, source-note retention, circuit restoration and short-circuit diagnostics, wave speed/crest timing, real/virtual/infinite lens cases, probe endpoint temperatures, induction polarity/current, sinking equilibrium, corrected vernier arithmetic, photoelectric intensity independence and the six-trial/work-function guards. Direct drag and button interactions and close/reopen retention are exercised.

Layout checks scroll all ten panels at **320 × 568** portrait and **640 × 320** landscape with **200% text**, including filled replay and six-trial content. Tests load the bundled Manrope font. Optional `--dart-define=FOCUS_VISUALS=true` writes ten synthetic widget-rendered previews under ignored `Target UI/topTenUXScreens`; these are not native-device screenshots.

Exact final command results are recorded in `TOP_TEN_LAB_UX_VALIDATION.json`. Android compilation is checked with an ordinary debug APK. No physical-device, release-performance or iOS runtime certification is implied. The existing dedicated emulator and its saved learner data were not modified for this change.
