# Shared and studio-specific UI/UX improvements

**10 common improvements + 10 tailored tools in each of 17 studios = 180 review items.**

The common workbench serves all 116 physical labs. The six Concept Overview tools have 10 focused discovery actions. Studio tools wrap the existing scientific models with previewed setups, focused readings, reversible controls and explicit evidence; they are not additional physics engines.

Open **Lab options → Exploration workbench** in a physical lab, or **10 studio tools** from a studio page. Opening a studio tool only opens its lab and preview; applying a setup and capturing evidence are explicit actions. The earlier lab-specific Tune/Compare/Watch/Plot/Explain tools remain available.

## Ten common improvements

1. **Searchable controls** — Find inputs by name, symbol or unit, see the result count and clear the filter.
2. **Precise bounded entry** — Open the existing precision editor beside every current control, with its live range and units.
3. **Selectable fine steps** — Choose 0.01%, 0.1% or 1% of the current control range; use named decrease/increase buttons without dragging.
4. **Previewed paired setups** — Inspect actual A/B control values and units before applying a studio setup; unavailable mode controls block the whole change.
5. **Setup undo and redo** — Undo and redo complete source configurations, including model options and time; recorded trials remain separate.
6. **Baseline change ledger** — Review changes from the temporary opening reference, replace that reference explicitly, or restore it with Undo available.
7. **Focused live readings** — Search calculated readings, pin useful quantities to the top and switch between the curated focus and all values.
8. **Visible capture readiness** — Show current validity and the full source notice; block evidence capture until the apparatus/model is ready.
9. **Fair A/B interpretation** — Capture two actual paused states; show changed conditions and compute a secant only for one changed input, matching mode/units and equal available model time.
10. **Deliberate evidence sharing** — Copy only the selected setup inputs, calculated readings and explicit A/B evidence; source notes and histories are excluded.
