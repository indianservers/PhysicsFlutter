## Profile observations

The final profile target passed in **38s**. Each case collected ninety real frames on the isolated host-GPU emulator. The orbit case explicitly selects a circular initial state before playback so the benchmark does not accidentally measure a stopped impact trajectory. Resonance uses the actual driven oscillator; coupled motion uses the real two-mode solution. Raw values are in `screenshots/phase3-profile.json`.

- Orbit: median build 1.072 ms, p95 build 1.636 ms; median raster 2.049 ms, p95 raster 6.819 ms; p95 total **27.800 ms**; 24/90 totals above 16.67 ms.
- Resonance: median build 1.263 ms, p95 build 2.464 ms; median raster 3.483 ms, p95 raster 26.064 ms; p95 total **43.831 ms**; 41/90 totals above 16.67 ms.
- Coupled: median build 1.292 ms, p95 build 2.556 ms; median raster 3.700 ms, p95 raster 10.746 ms; p95 total **35.426 ms**; 39/90 totals above 16.67 ms.

There is remaining emulator frame-time jank, especially the resonance raster tail. This is not a verified 60 fps result and is not directly comparable to the earlier Phase 2 profile because emulator allocation/rendering workload changed. Further physical-device profiling and optimization remain explicit release work. The final pendulum scene was also recaptured in this native profile run to verify that its stand clears the complete large-angle path.
