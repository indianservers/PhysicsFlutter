# Phase 6 assets and earlier-module audit

Inspected all twelve panels of `Target UI/13_Electronics.png` and `14_Thermodynamics.png`, earlier handovers/model notes, architecture, routes/catalogue, notebook schema, shared fixed clock, MNA solver, graph scales and rendering helpers. The baseline had 147 passing tests. Before-native captures cover home, studios 1/6/8/10/11/12/13 and twelve representative earlier labs. The exact SQLite/shared-preferences backup is local at `C:\tmp\phase6-baseline-exact.tar`; it is not committed.

New `features/electronics_thermal/scene.dart` geometry is original Flutter Canvas code. Lattice/band representations, series diode and cathode band, generic E–B–C transistor, generic IC, simulated sensor module, sample vessel/probe, steady rod, ordinary gray thermal body, finite-body contact and state-linked gas piston are procedural. No generated raster, downloaded image, 3-D model, new font, texture or external apparatus asset was introduced. Labels reuse the existing bounded `ScientificText` cache. Existing material assets/plugins retain their earlier provenance and licenses. Bundled Material icons retain Flutter's existing licensing. The user's boards remain excluded from Git and app assets; no redistribution rights are claimed.

The apparatus is a schematic educational rendering, not photographic or CAD parity with the boards. Lattice dots do not count physical carriers. Breadboard sockets and generic package leads do not certify a commercial chip pinout. Circuit conductors show functional nodes; named-device pinouts are deliberately avoided. The sensor modules are offline transfer-function simulations. No steam, sparks, glowing room-temperature rods, actual phone-sensor data or microscopic particle dynamics is fabricated.

Earlier-module change: electromagnetic `EMPainter.shouldRepaint` previously always returned true, so parent rebuilds for notes and unrelated UI state rerasterized the whole apparatus. It now snapshots physics revision and circuit layout, and compares model identity, camera, selection and overlay settings. Snapshotting is essential because the run and circuit are mutable: comparing only their current values would miss subsequent physical/layout changes. A regression explicitly checks stable-state suppression and each relevant invalidation. Scientific calculations, cached geometry and all 66 existing lab IDs remain unchanged. This is a targeted redundant-paint fix, not a claim that the previously measured field/Boris raster jank is resolved.

Other integration improvements: Overview's launcher and guided sequence now include Electronics/Thermodynamics and 78 interactive labs; the availability label reports Phase 6; database trial decoding accepts the new SI quantities/model without a schema replacement. The catalogue remains 17 studios / 102 stable destinations. No dependency or permission is added. Phase 7 studios remain introductory.

Known visual/performance work still needed: photographic apparatus quality, richer manufacturer-specific component models, physical-device GPU profiling and independent accessibility user testing. These limitations are not hidden by marking the next phase complete.

The amplifier now draws its functional feedback network explicitly, with the correct grounded/input port for each mode. Piston height is proportional to calculated volume within an automatically framed configuration. Thermal false colours use a stated 273–353 K scale; flux-arrow direction follows the signed computed rate, including inward transfer and zero equilibrium flux.

Unchanged wood texture, breadboard grid and rails occupy a separate `ETBackdrop` repaint boundary. Their drawing is independent of the physics tick and is eligible for raster reuse; the transparent foreground contains the changing scientific apparatus/readings. The before-cache and after-cache native profile JSON files are retained without claiming that host/emulator variance is isolated.
